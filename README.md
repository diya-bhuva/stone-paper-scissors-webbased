
# Rock Paper Scissors Game 🎮

A simple and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**.

## 🚀 Features

- 🪨 Rock, 📄 Paper, and ✂️ Scissors choices
- 🤖 Random computer choice
- 🏆 Winner/loser result
- 📊 User and computer score tracking
- 🔄 Draw detection
- 🖱️ Interactive hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎮 How to Play

1. Open `sps.html` in your browser.
2. Select Rock, Paper, or Scissors.
3. The computer will randomly choose one.
4. The game will display the result.
5. The score will be updated automatically.

## 🧠 Game Rules

- 🪨 **Rock beats Scissors**
- ✂️ **Scissors beats Paper**
- 📄 **Paper beats Rock**
- 🤝 Same choices result in a **Draw**
